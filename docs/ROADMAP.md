## 2. 러프 계획 보완

| 원래 계획 | 보완 |
|---|---|
| 랜덤 뽑기 2가지 | 방식을 늘리기보다 **필터**를 먼저 붙인다 ("안 가본 곳만", "도 선택"). 아래 3절 참고 |
| 로그인 필요? | 필요하다. 단 **뽑기와 일정 미리보기는 로그인 없이** 쓴다. 저장·초대·사진을 누를 때 로그인을 요구한다 (첫 사용 장벽 최소화) |
| 혼자/친구 | 지금의 "링크만 알면 편집"은 로그인 도입 후 **초대 링크 → 로그인 → 멤버 등록**으로 바꾼다. 누가 고쳤는지 보이고, 링크가 새도 아무나 못 들어온다 |
| 사진 등록 + 후기 등록 | 둘을 **'기록' 하나로 합친다**. 사진만 올려도 되고 글을 붙이면 후기가 된다. 테이블·화면·피드가 하나로 줄어든다 |
| 다녀온 지역 색칠 | 기준을 정해야 한다 → 여행에 **상태(계획 중 / 다녀옴)** 를 두고, "다녀옴" 처리하면 그 지역이 칠해진다. 날짜도 같이 받는다 |
| 다른 유저 후기 | 기록마다 **공개/비공개** 선택. 기본값은 비공개. 공개 피드가 생기면 **신고·숨김**과 **약관·개인정보 처리방침**이 같이 있어야 한다 |
| 제휴 | 지금은 만들지 않는다. 대비만 한다: 기록에 선택 입력 "장소 이름" 칸 하나. 나중에 장소별로 모으면 제휴 단위가 된다 |
| 사진 용량 | 올리기 전에 브라우저에서 긴 변 1600px·webp로 줄인다(약 300KB). 다시 인코딩하면 EXIF(GPS)도 같이 지워진다. Supabase 무료 1GB ≈ 3,000장 |

### 페이지를 나눌까? → 나눈다 (React로)

한 파일로 버티면 화면이 4개를 넘는 순간 다루기 어렵고, 지역 피드는 링크로 공유될 수 있어야 한다. 앞으로 화면이 계속 늘어나니 **React로 옮기고 라우트로 나눈다.**

**스택**: Vite + React + React Router + `@supabase/supabase-js`(npm). 스타일은 **일반 CSS + 지금 `:root` 토큰 그대로** (Tailwind·UI 라이브러리 안 씀 — Hallmark 토큰을 그대로 살리려고). TypeScript는 안 씀. `api/plan.js`는 Vercel 함수로 그대로 둔다.

| 주소 | 화면 | 레이아웃 |
|---|---|---|
| `/` | 뽑기 (룰렛·다트) | 지도 \| 패널 (지금 그대로) |
| `/plan/:id` | 일정 보기·편집·초대 | 지도(뽑힌 지역 강조) \| 패널 |
| `/me` | 내 지도: 다녀온 지역 색칠, 내 여행 목록 | 지도 \| 패널(목록) |
| `/region/:id` | 지역 피드: 내 기록 / 모두의 후기 | 지도(그 지역 확대) \| 패널(피드) |

공통 컴포넌트: `<Layout>`(지도 \| 패널 2단 + 상단 내비: 뽑기 · 내 지도 · 프로필), `<KoreaMap>`(regions.json 그리기, 지역별 색·클릭·hover를 props로). 모든 화면이 이 둘을 같이 쓴다.

## 3. 뽑기 방식 제안

지금 두 방식(룰렛·다트)은 유지. 추천 순서:

1. **필터 (강력 추천)** — "안 가본 곳만", "도 선택", "바다 있는 곳". 룰렛·다트 둘 다에 적용된다. "안 가본 곳만"은 내 지도와 바로 연결돼서 앱을 계속 쓸 이유가 된다.
2. **카드 3장 뽑기** — 3곳을 뽑아 카드로 뒤집어 보고 하나를 고른다. 완전 랜덤이 부담스러운 사람용. 뽑고 고르는 순간마다 애니메이션을 넣어 영상으로 보기 좋게 만든다.

## 4. 추가 기능 제안

1. **정복 지도 공유 카드** — "전국 167곳 중 23곳" 이미지 저장·공유. 바이럴·쇼츠 소재로 가장 좋다.
2. **도 단위 완주 표시** — 강원 18곳 중 18곳 → 도 테두리 강조. 다음 여행 동기.
3. **함께 간 여행 공동 앨범** — 같은 여행의 멤버는 서로의 사진을 한 피드에서 본다. (멤버 테이블이 있으면 거의 공짜)
4. **여행 D-day** — 일정에 날짜를 넣으면 내 여행 목록에 D-3 표시, 지나면 "다녀왔나요?" → 기록 유도.

### Phase B — 뽑기 보강

- [x] **B1. 다트 손보기**
  - 문제와 원인 (2026-10-11 코드 확인):
    - **잡는 곳이 헷갈림** — 실제로는 지도 어디서 눌러도 되는데, 다트가 맨 아래 좁은 판(높이 74)에 있어서 다트를 직접 잡아야 할 것처럼 보인다. 누른 손가락 위치와 다트 사이에 연결이 화면에 안 보이는 게 원인
    - **제주도를 못 맞힘** — 출발점에서 제주까지 약 100칸인데, 가장 약하게 던져도 약 130칸 날아간다. 힘 15% 미만은 던지기가 취소되고, 속도에 바닥값(120)이 있기 때문이다. 가까운 곳은 바람이나 각도가 받쳐줄 때만 맞는다
    - **울릉도·독도 위치** — 지금은 오른쪽 위 박스에 따로 있다. 실제 위치에 그리면 가로 약 480(울릉)·560(독도)으로 지도 폭 400을 넘는다
    - **손가락이 화면 밖으로 나가면 조준선이 남음** — `pointercancel` 처리가 없다
  - 할 일:
    1. **잡기 표시** — 누르는 순간 손가락 위치에 작은 링이 생기고, 링과 다트를 고무줄 선으로 잇는다. 다트 주변에 "어디서든 잡고 아래로" 안내. 던지는 판 높이를 늘리고, 모바일에서는 지도 아래 빈 곳에서 잡아도 되게
    2. **힘 → 거리 직선 대응** — 0%면 출발점 바로 앞, 100%면 지도 맨 위에 떨어지도록 속도를 거꾸로 계산. 취소 기준은 힘 %가 아니라 "8px 미만 당김"으로. 조준선 끝에 바람을 뺀 예상 낙하 지점 점선 원 표시
    3. **울릉도·독도** — 위도(높이)는 실제대로, 동쪽 거리만 줄여서 울진 오른쪽 바다에 박스 없이 놓는다. 실제 크기는 점에 가까우니 판정 영역을 넉넉한 원으로 키우고, 독도에 맞아도 울릉군으로 판정
    4. **다트 그림 다시 그리기** — 금속 촉, 손잡이 홈(그립 줄), 얇은 대, 날개 2장(원근감 있게). 날아갈 때 살짝 회전(대 축으로), 꽂히면 비스듬히 박힌 각도 + 지금의 부르르 진동. 색은 토큰만 (촉 `--color-ink-2`, 몸통 `--color-accent`, 날개 `--color-accent-wing`)
    5. **손맛** — 꽂힐 때 짧은 진동(`navigator.vibrate`, 지원 기기만), 바다에 빠지면 물결 동그라미 한 번
  - 완료 기준: 제주·울릉·서울을 각각 10번 안에 맞힘(자동 점검: 바람 0에서 목표 지점까지 필요한 힘을 계산해 던지기), 손가락이 화면 밖으로 나가도 조준선이 안 남음, 다트 확대 캡처로 그림 확인
  - 결과 (2026-10-11): 누르면 손가락 링 + 다트 꼬리까지 고무줄, 던지는 판 높이 74→110, "어디서든 잡고 아래로" 안내. 물리는 고정 간격(1/120초)으로 돌리고 힘→거리를 직선(0% = 20칸, 100% = 지도 맨 위)으로 맞춰 속도를 거꾸로 계산 → 바람 0이면 점선 원에 정확히 떨어짐. 취소는 8칸 미만 당김. 울릉도는 실제 높이·울진 앞바다(박스 없음), 판정 원(울릉 12·독도 7). 새 다트(금속 촉·그립 홈·날개 2장 회전·꽂히면 비스듬히), 진동 20ms, 바다는 물결. `pointercancel`·`lostpointercapture` 처리. `dart.mjs` 통과(제주 1번·울릉 3번·서울 1번, 390·1280 둘 다), `shots.mjs` 회귀 통과

- [x] **B3. 카드 3장 뽑기**
  - 할 일: 세 번째 탭 "카드". 3곳 뽑기(B2 필터 적용) → 아래 애니메이션 순서대로 → 고른 지역으로 일정 짜기
  - 애니메이션 순서:
    1. **섞기** — 카드 뭉치가 패널 가운데서 몇 번 엇갈리며 섞인다 (약 0.8초)
    2. **펼치기** — 3장이 부채꼴로 하나씩 깔린다 (카드마다 0.1초 간격)
    3. **뒤집기** — 카드를 누르면 3D로 뒤집힌다(`rotateY`). 앞면: 지역명 · 도 이름 · 그 지역 모양(regions.json path). 뒤집을 때 지도에서 그 지역이 잠깐 깜빡인다
    4. **고르기** — 3장이 다 열리면 하나를 누른다. 고른 카드는 커지며 가운데로, 나머지 2장은 흐려지며 아래로 빠진다. 지도는 고른 지역 강조
  - 디자인: 카드 뒷면은 네이비 accent 단색 + 지도에서 쓰는 다트 모양(흰색 선). 그림자·그라데이션 없이 토큰 색만. 애니메이션은 `transform`·`opacity`만 써서 폰에서도 끊기지 않게 (라이브러리 안 씀)
  - 완료 기준: 390px에서 카드 3장이 한 화면에, 1–4단계가 폰에서 끊기지 않음(캡처 영상으로 확인), `prefers-reduced-motion`이면 애니메이션 없이 바로 펼쳐진 상태로, 키보드로도 뒤집기·고르기 가능
  - 결과 (2026-10-11): 세 번째 탭 "카드" (`src/components/Cards.jsx`). 남은 곳(B2 필터)에서 겹치지 않게 3장(남은 곳이 3 미만이면 그만큼). 섞기 0.8초 → 0.1초 간격 부채꼴 → `rotateY` 뒤집기(지도 깜빡 + 상태창에 지역명) → 다 열면 고르기(커지며 가운데, 나머지 흐리게 아래로, 지도 강조 + 일정 짜기 버튼). 뒷면은 accent 단색 + 다트 흰 선. 카드는 `<button>`이라 Tab·Enter·Space로 뒤집기·고르기. 모션 줄이기면 섞기 없이 바로 펼침. `cards.mjs` 통과(390·1280 한 화면·키보드·모션 줄이기·제주만 30번), 영상 `shots/B3/video-*.webm`. 실제 폰 끊김은 배포본에서 손으로 확인 필요
  - 훅: "3장 중에 골라. 근데 뒤집기 전엔 어딘지 몰라"
