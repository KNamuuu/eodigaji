## 0. 세션 루틴

1. 이 문서에서 체크 안 된 첫 작업을 고른다.
2. 완료 기준을 브라우저(390px · 1280px)로 확인하는 점검 스크립트를 만들고 `shots/<작업번호>/`에 캡처한다.
3. 로컬(`npx vite preview --port 4173`) → 푸시 → 배포본(`BASE=https://eodigaji.vercel.app`)에서 점검 전체를 다시 돌린다.
4. 체크하고 커밋. 영상은 `/shorts-clip`.

DB 변경은 `supabase/schema.sql` 맨 끝에 덧붙이고 운영 DB에 바로 적용한다 (스키마의 단일 기준).

## 2. 남은 작업

### Phase E — 설정만 하면 되는 것 (사용자 할 일)

- [ ] **E0. 키·권한 넣기**
  - 카카오톡 공유: 카카오 디벨로퍼스 → 앱 → JavaScript 키 + [플랫폼 > Web]에 `https://eodigaji.vercel.app` 등록 → Vercel 환경변수 `VITE_KAKAO_JS_KEY` → 재배포. 공유 시트에 [카카오톡]이 생김
  - 관리자 지정: Supabase SQL `insert into public.admins select id from auth.users where email = '<내 로그인 이메일>';` → `/me`에 [신고 관리]
  - 구글 로그인 공개: Google 인증 플랫폼 브랜딩에 홈·`/privacy`·`/terms` 넣고 [앱 게시] (지금은 테스트 사용자만). 콜백 `https://ltbhffozitpbsxjbnbnd.supabase.co/auth/v1/callback`

### Phase F — AI 일정 (모델 정해짐, 키 대기)

  - 할 일: `api/plan.js` 모델을 Haiku 5.5 + effort `low`로, 키 넣고 실제 호출 검증, HH:MM 형식 확인, 로그인 사용자만(Supabase JWT 확인 — 비용 보호), 사용자당 하루 호출 제한, 실패 시 샘플 유지
  - 완료 기준: 실제 지역 3곳 생성 성공, 비로그인 401
- [ ] **F2. AI 일정 조건** — 당일치기/1박2일, 차/대중교통, 먹방/힐링 칩 → 프롬프트 반영, [다시 짜기]

### Phase G — 앱 + 알림

- [ ] **G1. 앱으로 감싸기 (Capacitor)** — 지금 웹 코드를 그대로 iOS·Android 앱(웹뷰)으로. 스토어 등록, 아이콘·스플래시, 딥링크(`/invite/…`를 앱에서 열기), 카카오·구글 로그인 리다이렉트 확인
- [ ] **G2. 알림 기반** — `notifications` 테이블(받는 사람·종류·링크·읽음) + 앱 안 알림함(헤더 종 아이콘)
  - 보낼 것: 친구가 초대를 수락함 · 같이 쓰는 여행이 바뀜(묶어서 한 번) · 내 공개 일정을 누가 따라 짬/♥ · 내 기록·일정이 신고로 숨겨짐/되살아남 · 가는 날 하루 전 · 다녀온 다음 날 "기록 남길까요?"

### Phase H — 기록 다듬기

- [ ] **H1. 기록 사진 순서 바꾸기·추가하기** — 수정 화면에서 끌어서 순서, [+ 사진]. `posts.photos` 수정은 내 폴더 경로만 허용(RLS)
- [ ] **H2. 닉네임·프로필 사진 바꾸기** — `/me`에서. `profiles`와 헤더 표시를 같이 바꿈

### 보류 (설명 듣고 결정)

- 친구 지도 비교: 같이 여행한 친구와 내 지도를 겹쳐 "둘 다 간 곳 / 나만 / 친구만" 3색. 친구 관계와 지도 공개 범위 설정이 먼저 필요
- 공유 카드 기간 고르기: 카드에 [전체 / 올해 / 2025년] 선택 → 그 기간에 다녀온 곳만 칠함. 연말 "올해 정복 지도"용
- 제휴 장소 노출·쿠폰 → 장소별 기록이 쌓이면 다시 검토
- 출발지 기준 거리 필터 → 지역 좌표(`cx`,`cy`)는 이미 있음

## 3. 디자인 규칙 (Hallmark 유지)

- 기준: `src/index.css` 상단 — Workbench(지도 \| 패널), light / grotesk-sans / cool, "지도 앱처럼 조용한 도구", Pretendard 단일 서체, 네이비 accent.
- 새 화면은 `<Layout>`·`<KoreaMap>`을 재사용해서 **지도 \| 패널 2단**. 모바일은 지도 → 패널 1단.
- 색·간격은 `:root` 토큰만. 새 색이 필요하면 토큰을 추가한다.
- 사진은 패널 안 2열 격자(썸네일), 크게 볼 때만 원본. 그림자·그라데이션 추가 금지.
